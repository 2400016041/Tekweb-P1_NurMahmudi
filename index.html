Belajar CSS Dasar

CSS digunakan untuk memperindah tampilan halaman website agar lebih menarik, rapi, dan mudah dibaca.

Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa stylesheet untuk mengatur tampilan elemen HTML, seperti warna, ukuran teks, jarak, dan tata letak.

Box Model

Box Model terdiri dari content, padding, border, dan margin. Keempat bagian ini membantu mengatur ukuran serta jarak elemen.
